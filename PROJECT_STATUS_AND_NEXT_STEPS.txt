PROJECTCOLLAB
Project status and completion roadmap
Updated: October 26, 2026

1. PROJECT PURPOSE

ProjectCollab is a college-only collaboration platform for students. It helps
verified students create project opportunities, discover suitable teams, apply
for roles, manage team membership, work together in a private workspace, and
track updates.

The project is separated into two applications:

- frontend/  React + Vite user interface
- backend/   Express API + PostgreSQL database

4. DATABASE STATUS

PostgreSQL is required for real accounts and persistent data.

The database schema and migrations currently included are:

- backend/db/schema.sql
- backend/db/migrations/002_student_profiles.sql
- backend/db/migrations/003_projects.sql
- backend/db/migrations/004_applications.sql
- backend/db/migrations/005_collaboration_workspace.sql
- backend/db/migrations/006_notifications.sql
- backend/db/migrations/007_bookmarks.sql

To prepare a development database:

1. Install PostgreSQL.
2. Create a database:
   createdb projectcollab
3. Copy backend/.env.example to backend/.env.
4. Set DATABASE_URL and the authentication secrets in backend/.env.
5. Apply the base schema:
   psql "$DATABASE_URL" -f backend/db/schema.sql
6. If the database was created before a new migration existed, apply that
   migration separately. For example:
   psql "$DATABASE_URL" -f backend/db/migrations/007_bookmarks.sql
